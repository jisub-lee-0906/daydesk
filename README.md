# daydesk · 내 PC 데스크

ComfyUI·GPU, AI 사용량·구독, 날씨·테크뉴스를 한 화면에 보는 개인 Windows 대시보드입니다. Python 표준 라이브러리와 HTML/CSS/JavaScript만 사용합니다.

1. **Open Dashboard.cmd**를 더블클릭하면 http://127.0.0.1:8765/ 가 기본 브라우저에서 열립니다. 재실행해도 수집기는 하나입니다.
2. 날씨는 **용인**이 기본입니다. **위치 설정 → 현재 위치 사용**에서 안내를 읽고 브라우저 위치 권한을 허용하면 위치 변화에 따라 갱신합니다. 이 앱의 브라우저에서 위치를 얻지 못하면 용인으로 복귀합니다. 기본 브라우저에서도 위치 서비스·권한이 필요합니다.
3. **Stop Dashboard.cmd**로 수집기를 종료합니다. 자동 시작·서비스·전역 패키지는 설치하지 않습니다.

## 화면

아이보리 바탕에서 VRAM 여유를 먼저 보고, AI 사용 비율은 행별로 비교합니다. 뉴스는 행 전체를 클릭할 수 있으며, 구독 설정은 목록만 스크롤되어 저장·취소 버튼이 계속 보입니다.

- ComfyUI: 기존 Desktop(8188) 연결, 실행·대기 개수, NVIDIA GPU의 VRAM 사용/여유·전체, 온도·사용률. VRAM은 **GPU 전체** 값입니다.
- AI: Codex / Claude / Grok / Gemini의 최근 로컬 캐시 사용 비율과 플랜·서비스 바로가기. 구독 설정에서 금액·통화·주기·갱신일을 편집합니다. 마지막 확인 플랜과 직접 입력 금액을 구분하며 실제 결제를 자동 조회하지 않습니다.
- 날씨: 현재 기온·날씨·최고/최저·강수확률. Open-Meteo의 도시 주변 예보이며 관측 장비의 실측값을 의미하지 않습니다.
- 뉴스: GitHub Changelog, Hugging Face Blog, GeekNews의 원문 제목·출처·게시 시각. 전체/출처별로 최대8개, HTTPS 원문을 별도 탭으로 엽니다. 번역·요약 모델은 호출하지 않습니다.
- PC 상태는 작은 줄로, 앱별 메모리와 구독 상세는 **상세 정보** 안에 접어 두었습니다. 집중 목표·할 일·독립 바로가기 UI는 제거했지만 기존 localStorage 데이터는 보존합니다.

## 위치와 외부 연결

현재 위치 사용은 명시적으로 켠 뒤 동작합니다. 정밀 좌표는 브라우저에서 0.1도(대략10km) 단위로 줄인 후 로컬 서버에 보내며, Open-Meteo에는 그 대략적 좌표로만 날씨를 요청합니다. 위치 이력과 현재 위치의 날씨는 디스크에 저장하지 않습니다. 반올림된 좌표도 메모리에만 두고, 탭 숨김·추적 오류·90초 임대 만료·재시작 시 용인으로 돌아갑니다. 위치가 흔들릴 때 같은 칸은 재전송하지 않고 변경 위치의 기상 요청도 최소5분 간격으로 제한합니다. 여러 탭이 서로의 위치를 해제하지 않도록 탭별 임대를 사용합니다.

브라우저의 위치 확인 자체에는 OS/브라우저의 위치 제공 서비스가 관여할 수 있습니다. 앱의 날씨·뉴스는 공개 인터넷 조회이며 PC 상태·프로세스·구독·계정 정보는 외부로 보내지 않습니다. 뉴스 링크를 누르면 해당 사이트에 접속합니다. 서버는127.0.0.1 전용이며 고정 경로·Host/Origin 제한·CSP를 적용합니다. 위치 POST는 같은 Origin의 JSON만, 본문512bytes 이내로 받습니다.

## 자원과 캐시

PC/GPU3초, ComfyUI 큐6초, 앱15초, AI 캐시30초. 날씨30분, 뉴스1시간 캐시이며 화면이 숨겨지면 브라우저 폴링·위치 추적을 멈춥니다. 공개 인터넷 작업자는 PC 수집기와 별도 스레드이므로 느린 뉴스가 PC 갱신을 막지 않습니다. 조회 없는 상태가120초를 넘으면 공개 수집도 쉽니다. 기본 용인 날씨와 제목 캐시만 .run/public-cache.json에 원자적으로 저장해 재시작·오프라인에 재사용합니다. 실패하면 같은 지역의 마지막 성공값과 시각을 유지하며 오래됨을 표시합니다.

각 응답은 최대2MiB, 소스당12개/전체36개 제목만 메모리에 보관합니다. XML DTD를 거부하고 HTML 본문·이미지는 보관하지 않습니다. socket timeout8초, 기본 날씨 오류 재시도60초/뉴스 오류300초입니다. 초기 GPU 미포함 수집기는 약25MiB, GPU 포함 약47MiB, 날씨·뉴스 포함 활성 상태는 약53MiB로 관찰했습니다. 브라우저 메모리는 별도·미측정이며 서로 다른 기능 구성 간 성능 향상 수치는 주장하지 않습니다. 초기40MiB 목표는 충족하지 못했습니다.

GPU는 기존 NVIDIA 드라이버 NVML DLL로 읽으며 CUDA 컨텍스트나 측정용 자식 프로세스를 만들지 않습니다. 차트 라이브러리·Electron·반복 PowerShell/WMI·모델 호출이 없습니다. GPU/ComfyUI/캐시를 읽을 뿐 생성·중단·모델/계정 설정 변경을 하지 않습니다.

## 파일과 검증

dashboard.json의 opencodex_port10100 / comfyui_port8188은 이 PC에서 확인한 주소입니다. 바꾸면 수집기를 재실행합니다. launcher.py는 기존 Codex 번들 Python을 사용하며 .run에 로그·프로세스 생성시각·공개 캐시를 저장합니다. 번들 경로가 이동하면 cmd의 DESK_PYTHON을 기존Python3.12+ 경로로 바꾸면 됩니다.

Python: `python -X utf8 -B -m unittest discover -s tests -v`

Node: `node --test tests/ui.test.cjs tests/location.test.cjs`

Windows sandbox에서 소켓·임시파일 접근이 막히면 같은 검사를 호스트 권한과 프로젝트 .scratch TEMP/TMP로 실행합니다. 실제 실행·UI·위치 제한·모델 검토 증거는 EVIDENCE.md에 기록합니다.
